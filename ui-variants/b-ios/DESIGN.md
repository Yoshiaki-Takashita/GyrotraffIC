# DESIGN.md — 案 B「iOS ネイティブ」（b-ios）

## 美的な方向（1 つに決めて最後まで守る）
Apple の Human Interface Guidelines（HIG）の作法に忠実な、iPhone の標準アプリと地続きに見える画面。
「アプリが主張しない」静けさ。情報はグループ化された行（inset grouped list）で並べ、区切りは細い線。
主操作の色は 1 色（システムの青に近い色）だけ。路線の色は経路の線とアイコンの小さな面にだけ使う。

作法として守ること：
- 大きな見出し（Large Title 34pt）→ スクロールで上のバーに小さな題名（17pt・半太字）が現れ、バーは半透明のぼかしになる。
- 下部のタブ（3 つ・アイコン＋短い名詞）。半透明のぼかしは「上のバー・下のタブ・シートの上端」だけ（本文の上には使わない。読みやすさ優先）。
- 詳細は下から出るシート（中間の高さ＝画面の約 60%／大きい高さ＝上端の少し下）。つかみ（grabber）で上下に動かせ、離した速さで止まる位置が決まる。下に払うと閉じる。
- 区分の切り替えはセグメント（segmented control）。行の右端は「›」。破壊的な操作は赤い文字。
- 安全領域（env(safe-area-inset-*)）を上下とも尊重。

名指しで禁じるもの：Inter/Arial 風の無難な書体、紫のグラデーション＋白地、同じ形の角丸カードの無限の並び（結果は「行」で並べる）、意味のない飾りの動き、絵文字、Android 風の部品（浮かぶ丸い FAB・下線のタブ・波紋のエフェクト・ハンバーガーのメニュー）、ウェブ風の部品（下線のリンク・枠だけのボタンの多用・ホバー前提）、Apple のロゴ・SF Symbols の複製（アイコンはすべて自作の SVG）。

## 書体（外部フォント・CDN なし）

## 余白（4 の倍数）
`--s1:4px --s2:8px --s3:12px --s4:16px --s5:20px --s6:24px --s8:32px --s10:40px`
左右の基本の余白は 16px（320px 幅のときも 16px）。行の高さは最小 44px（標準 48px）。

## 角の丸み
`--r-row:10px`（グループの角）、`--r-ctl:9px`（セグメント・入力）、`--r-btn:14px`（大きいボタン）、`--r-sheet:14px`（シートの上の角）、`--r-icon:7px`（行のアイコンの面）。

## 影
`--sh-sheet: 0 -1px 0 var(--sep), 0 -8px 30px rgba(0,0,0,.12)`（シートだけ）。グループの行には影を付けない（面の色の差だけ）。
`--sh-thumb: 0 3px 8px rgba(0,0,0,.12), 0 3px 1px rgba(0,0,0,.04)`（セグメントのつまみ）。

## 動き
| 場面 | 長さ・曲線 | 動きを減らす設定のとき |
|---|---|---|
| シート（見せ場 1） | ばね：硬さ 420・減衰 38（ほぼ臨界。ゆれは 1 回未満）。離した速さを 0.2 秒ぶん先読みして止まる高さを選ぶ | ばねなし。0.01 秒で位置へ |
| 経路の線（見せ場 2） | 線が 520ms で伸び（`--ease-out: cubic-bezier(.2,.8,.2,1)`）、駅の点が線の到達に合わせて順に点灯 | 最初から描いた状態 |
| 時刻の数字（見せ場 3） | 桁ごとに縦に流れる 420ms（`--ease-spring: cubic-bezier(.32,1.15,.48,1)`。わずかに行き過ぎて戻る）、桁ごとに 22ms ずらす | 即時に差し替え |
| 結果→詳細（見せ場 4） | 押した行の時刻が、シートの見出しの位置まで移る 380ms（共有要素） | 動かさない |
| 大きな見出し→バーの題名 | スクロール量に連動（時間の動きでなく位置の連動） | 同じ（動きではない） |
| 押したときの反応 | 行の背景が `--fill` に 0ms で変わり 200ms で戻る | 同じ |

`--dur-1:200ms --dur-2:320ms --dur-3:420ms --dur-4:520ms`
常時回る動き・3D・シェーダーは使わない。
