# 案 D「計器」 DESIGN.md

## 美的な方向（1 つ）
航空機の計器盤。暗い面に、少数の「計器」だけが静かに光る。名前 GyrotraffIC の gyro（姿勢計）・traffic（経路）・IC（精密な部品）に合わせる。
飾りは引き算で、意味のある目盛りだけを置く。情報は「大きな数字」「細い目盛り」「1 本の経路のリボン」で表す。

禁じるもの：Arial/Inter 風の無難な書体の指定／紫のグラデーション＋白地／同じ形の角丸カードの並び（一覧は細い線で区切る行にする）／意味のない飾りの動き・常時回る動き／ネオンの過剰・重いシェーダー・ゲーム風の装飾／絵文字。

## 書体
- 文章：`--font-text` = system-ui, -apple-system, "Hiragino Sans", "Hiragino Kaku Gothic ProN", "BIZ UDPGothic", "Noto Sans JP", "Yu Gothic UI", Meiryo, sans-serif（外部フォントなし。日本語の端末の標準を優先）
- 数字（時刻・所要時間・目盛り）：`--font-num` = ui-monospace, "SF Mono", Menlo, "Cascadia Mono", "Roboto Mono", "Noto Sans Mono", monospace ＋ `font-variant-numeric: tabular-nums`
- 字の大きさ：11 / 12 / 13 / 15 / 17 / 22 / 34 / 48 px（`--fs-2xs`〜`--fs-3xl`）。区画の見出しは 11px・字間 .08em（計器の銘板）
- 行間：本文 1.65（日本語）、数字 1〜1.25

## 余白・角・影
- 余白：4 の倍数（`--s1` 4 〜 `--s10` 40）。左右の余白 16px（320px 幅では 12px）
- 角：2px / 4px。丸はタップの入れ替えボタンと節・姿勢計だけ
- 影：使わない。奥行きは線と発光（ダークのみ）で示す

## 動き
| 場面 | 長さ・曲線 | 動きを減らす設定 |
|---|---|---|
| 起動：水平線が傾きから水平に定まる | 620ms・`--ease-settle`、700ms から 200ms で消える（合計 0.9 秒・1 回だけ） | 出さない |
| 姿勢計：検索中に静かに揺れ、結果で水平に定まる | 揺れ 2.4s 往復（検索中だけ）、定まる 900ms・`--ease-settle` | 最初から水平で静止 |
| 所要時間の機械式カウンター | 700ms・`--ease-out`、桁ごとに 70ms ずらす | 最終値を即表示 |
| 経路のリボン：線が伸び、節が順に点灯 | 全体 760ms（区間の時間に比例）、節の点灯 180ms | 全部点灯した状態で表示 |
| 押したときの色の変化 | 140ms | なし |

動きは transform と opacity だけ（合成で済む）。常時の動きはない（姿勢計の揺れは検索中だけ、時計は 1 分ごとの書き換え）。
