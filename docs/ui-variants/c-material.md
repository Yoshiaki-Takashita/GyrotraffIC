# 案 C「Material」（c-material）

**結論**：Android の Material Design 3 の作法に忠実な案。検索→結果→詳細→保存→設定は基本の UI と同等に動き、自動検査（3 幅×ライト／ダーク、コンソールエラー 0・横スクロールなし・タップ 44px 以上・コントラスト AA）はすべて合格。自己点検の最終は 50 点中 42 点。実機での確認はしていない（不明）。

## 要約（非エンジニア向け）
1. Android の標準アプリに近い見た目と操作。説明なしで使える。
2. 色は青緑 1 色から作った明るさの段だけ。線の箱ではなく、面の明るさで区切る。
3. 下に「検索・保存・設定」のバー。選んでいる所は丸い帯で示す。
4. 検索のボタンは右下の大きな丸い四角（親指の届く所）。
5. 結果は一番よい案だけ色の面にして、目が最初にそこへ行く。
6. 並び順を変えると、所要時間の数字が流れて切り替わる。
7. 案を押すと、その案が下から詳細の面に伸びる。
8. 詳細では経路の線が上から描かれ、乗り換えの点が順に現れる。
9. 動きを減らす設定の端末では、動きをすべて止めて即時に表示する。
10. 短所：Android らしさが強く、iPhone の利用者には少し「借り物」に見える。

## 方向と理由
- 所有者の方針「洗練・シンプル・引き算」に対し、M3 の tonal な面（面の段 5 つ）だけで階層を作れば、枠線や影をほぼ使わずに済む。影は FAB とシートの 2 か所だけ。
- 日本の利用者の約半分は Android。標準の作法（ナビゲーションバー・拡張 FAB・セグメントボタン・主のタブ・状態の層）に合わせると学習が要らない。
- 書体は Roboto＋Noto Sans JP 系（Android では標準搭載）。本文の行の高さは M3 の 24px でなく 26px（日本語の読みやすさ）。数字は等幅数字。
- トークン（色の役割・字の段階・余白・角・動き）は `ui-variants/c-material/DESIGN.md`。CSS はその変数だけを使う。
- 禁止した既定値：無難な書体の指定、紫のグラデーション、同じ形のカードの並び（結果は先頭だけ主の容器色、他は 1 つの面に 2px の間で連結）、絵文字、iOS 風の部品、Google の商標ロゴ（ブランドの印は自作 SVG）。

## 検証
- `NODE_PATH=/opt/node-tools/node_modules node ui-variants/c-material/tests/check.mjs`：390×844・360×800・320×640 × ライト／ダーク、検索→結果→安値タブ→詳細→保存→飛行機の詳細→保存一覧→設定→履歴の消去→ライセンス→アカウント、PC の中央の枠（390×844）、保存が使えない環境。結果：**すべて合格**（コンソールエラー 0・外部通信 0・横スクロールなし・タップ 44px 以上・ラベルあり・コントラスト AA）。撮影は動きを減らす設定で行った（動きの途中を写さないため）。
- `tests/motion.mjs`：見せ場の fps（上の表）と、動きを減らす設定で線の描画をしないこと（draw=0）を確認。コンソールエラー 0。
- スクリーンショット：`docs/ui-variants/c-material/`（18 枚・0.96MB）。主要 3 枚：`390x844-light-2-results.png`・`390x844-light-3-detail.png`・`390x844-dark-3-detail.png`。

## 長所と短所（正直に）
- 長所：Android の利用者は学習ゼロ。面の段だけで階層を作るので静か。トークンが M3 の役割名なので、将来 Android のネイティブ（Jetpack Compose の MaterialTheme）へ移すときに色・字の段階をそのまま写せる。動的な色（壁紙の色）にも役割の差し替えで対応できる。
- 短所：iPhone では異質に見える（iOS 版を別に作るか、どちらにも寄せない案と比べる必要）。個性は弱め。View Transitions は Safari の対応が新しく、古い端末では①が普通の切り替えになる。拡張 FAB は狭い画面で内容に重なる。

## 実機での確認が必要なこと（未実施・不明）
- 実機のスマホ（Android・iPhone）での表示・fps・電池（走らせていない：この環境に実機がないため）。
- Roboto／Noto Sans JP が無い端末（iPhone はヒラギノに落ちる）での字の幅と折り返し。
- 安全領域（ノッチ・ジェスチャーバー）での下部のバーと FAB の位置。
- View Transitions の実機ブラウザ（Android Chrome・iOS Safari）での挙動。
- 画面の読み上げ（TalkBack・VoiceOver）で、流れる数字が全文で読まれるか（aria-label で対応したが未確認）。
