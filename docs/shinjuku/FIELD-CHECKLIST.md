# 新宿駅 現地確認チェックリスト（下書き・2026-10-19）

目的：モデル（`data/shinjuku/shinjuku-station.json`）の「推」を、見て確かめた物から「確」にするための記録。
優先：**ホーム階とエレベーターの経路**。順番は COVERAGE.md の「不明（要現地確認）」と同じ。

## 先に決めておくこと

- 構内の撮影は各事業者（JR東日本・小田急・京王・東京メトロ・都営）の決まりに従う。三脚・長時間の撮影・業務用と見られる撮影は、事前に駅へ相談する。
- 人の顔が写らないように撮る（床・天井の案内・設備だけを狙う）。写ったら記録に使う前にぼかす。
- 構内図・案内板の**図そのもの**はモデルに写さない。撮るのは「その場所に何があるか」の証拠として。番号・文字（番線・号車・出口番号）を読み取るのはよい。
- 混む時間（7〜9 時・17〜20 時）を避ける。

## 1 件の記録のしかた（スマホのメモにこの形でコピー）

```
ID:            （下の表の ID。表にない物は「新規」）
日時:          2026-__-__ __:__
場所:          （階・番線・近くの出口番号など、見たままの言葉で）
あるか:        ある ／ ない ／ 工事中 ／ 立入禁止
種類は合うか:  合う ／ 違う（実際は：　　）
位置のずれ:    だいたい __ m（どちらへ）
写真:          P1 ____ ／ P2 ____ ／ P3 ____（ファイル名）
メモ:
```

写真のファイル名は `日付_ID_番号.jpg`（例 `20261101_TG28994867_P1.jpg`）。写真の位置情報（GPS）は地下では当てにならないので、場所は文字でも書く。

## 記録のあと（モデルへの反映）

- 確かめた物だけ `conf` を「確」にし、`confirmedBy`（日付・確認者・写真のファイル名）を付ける。
- 「ない」と分かった物は消さずに `status:"現地でなし"` を付け、日付を残す。
- 推測の接続（`derived-fix`）が正しければ「確」に、違えば消して正しい接続を足す。
- 写真そのものはこのリポジトリに入れるか別に保管するか、人が決める（容量・写った物の権利）。
