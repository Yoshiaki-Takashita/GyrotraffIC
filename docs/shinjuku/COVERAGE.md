# 新宿駅 3D マップ：データの集まり具合（2026-10-19 時点）

結論：公的なオープンデータだけで、トイレ・階段・エスカレーター・エレベーター・改札・ホーム・出口の**位置の下書き**と、階をまたぐ**歩行ネットワーク**までは作れた。
ただし「完全な再現」とは言えない。データは 2020〜2023 年の調査時点のもので、現地では確かめていない。また、階の高さ・線路の位置・号車とドアの位置・出口番号の体系は資料になかった。
モデルの全要素は `conf` を「推」としている（「確」は現地か事業者に確かめたものだけに付ける決まりで、いまは 0 件）。

モデル：`data/shinjuku/shinjuku-station.json`（形式 `gyrotraffic-station-v0`、ui-variants/e-station3d の見本と同じキー）。
作り方：`data/shinjuku/build_model.py`。件数の出どころ：`data/shinjuku/stats.json`。

注意：
- 国交省のデータは G空間情報センターで「ユーザ登録の後、ログイン状態でダウンロード」と案内されている。今回はログインせずに直接取れたが、**案内どおりユーザ登録してから取り直すことを勧める**（人の作業）。
- 国交省データの元資料には「新宿ターミナル協議会の新宿ターミナルマップ、駅構内図、施設平面図、フロアガイド」が挙がっている（meta.xml）。利用規約では「第三者の権利があるものは利用者の責任で許諾を得る」とされている。公開にあたっての権利処理がどこまで済んでいるかは**不明**。アプリで公開する前に、国交省へ確認するのが安全。

## 欠けている所の埋め方

| 欠けている物 | 埋め方 | 必要な人の作業 |
|---|---|---|
| 現在の状態（工事で変わった通路・出口・改札） | 現地調査（写真とメモ、階ごと） | 現地へ行く人・撮影の注意（構内撮影は事業者の決まりに従う） |
| 階の実際の高さ | 事業者に尋ねる。または基盤地図・3D 都市モデル（PLATEAU）の建物の高さで目安をつける | 問い合わせ |
| 線路・号車・ドア位置 | 事業者のデータ提供。ODPT に号車情報があるかキー取得後に確かめる | ODPT の利用登録（人） |
| 出口番号の体系 | 事業者・地下街の案内で確かめる。番号だけを事実として書き取るのは問題ないと考えられるが、図そのものは写さない | 確認作業 |
| 名前のないホーム 18 区画 | 現地確認、または事業者に確認 | 現地／問い合わせ |
| トイレの改札内外 | 現地確認。東京都データの改札の位置と重ね合わせて目安をつける | 現地 |

**事業者の構内図（JR東日本・小田急・京王・東京メトロ・都営の駅構内図、新宿ターミナルマップなど）は著作物。写したりなぞったりして使わない。** 使うなら、各事業者の利用許諾が必要になる。
国交省データは元資料にそうした図を挙げている。だから「公的データだから自由に使える」と決めつけず、権利処理の状況を確かめる。
