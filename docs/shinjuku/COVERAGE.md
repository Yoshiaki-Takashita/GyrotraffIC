# 新宿駅 3D マップ：データの集まり具合（2026-10-19 時点）

結論：公的なオープンデータだけで、トイレ・階段・エスカレーター・エレベーター・改札・ホーム・出口の**位置の下書き**と、階をまたぐ**歩行ネットワーク**までは作れた。
ただし「完全な再現」とは言えない。データは 2020〜2023 年の調査時点のもので、現地では確かめていない。また、階の高さ・線路の位置・号車とドアの位置・出口番号の体系は資料になかった。
モデルの全要素は `conf` を「推」としている（「確」は現地か事業者に確かめたものだけに付ける決まりで、いまは 0 件）。
2026-10-19 追記：東京都と国交省を 1 件ずつ突き合わせ、395 個の施設に「複数出典で一致」（`basis`）を付けた（`conf` は推のまま。詳細は CROSSCHECK.md）。ネットワークの切れ目を原因別に分け、一部を推測の接続（`src:"derived-fix"`・`guess:true`・`reason` に理由と距離）で直した（下の「ネットワークの切れ目」）。

モデル：`data/shinjuku/shinjuku-station.json`（形式 `gyrotraffic-station-v0`、ui-variants/e-station3d の見本と同じキー）。
作り方：`data/shinjuku/build_model.py`。件数の出どころ：`data/shinjuku/stats.json`。
